# D4RT 報告投影片（12 分鐘版）

- `D4RT_簡報.pptx`、`D4RT_簡報.pdf`：11 頁投影片，備註欄有講稿
- `講稿.md`：每頁要講的內容、時間和分工。廖晢勛講第 1–6 頁，林威宇講第 7–11 頁
- `build.js`、`slides_data.js`、`gen_script.js`：重新產生投影片和講稿用的腳本。執行 `node build.js` 和 `node gen_script.js`，需要先裝 pptxgenjs
- `figs/`：論文的圖和表，保留原本的圖說

## 圖表出處

`figs/` 裡的 Figure 1–4、Table 1、Table 6，都是從 Zhang et al., *Efficiently Reconstructing Dynamic Scenes One D4RT at a Time*, CVPR 2026 的 CVF Open Access 官方版本裁下來的，保留了原本的圖說，只用在課堂報告引用。著作權屬於原作者和 IEEE/CVF。這裡沒有放論文 PDF。
