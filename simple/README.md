# D4RT 簡化版報告（約 12 分鐘＋問答）

把原本 14 頁的版本精簡成 12 頁（11 頁內容加 1 頁 Q&A），分成六段：問題背景、核心想法（F 和 query）、同一個介面做多件事、速度與結果、限制與小結、問答。

- `D4RT_簡報_簡化版.pptx`、`D4RT_簡報_簡化版.pdf`：簡報檔，備註欄裡有講稿
- `口語講稿.md`：每頁的口語講稿、時間和講者分工（廖晢勛講第 1–6 頁，林威宇講第 7–11 頁）
- `QA.md`：助教可能會問的 5 題，加上幾題備用題
- `build.js`、`slides_data.js`、`gen_script.js`：重新產生簡報和講稿用的腳本（`node build.js`、`node gen_script.js`，需要 pptxgenjs）
- `figs/`：從論文裁下來的圖表，已去掉圖說
